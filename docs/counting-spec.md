# 集計仕様（文字数集計さん）

実装は `src/count.js`、テストは `tests/count.test.js`。数値・字種の判断は下記の実測と出典確認にもとづく。
画面と README に書くとおり、Word・SNS・応募フォームなどとは数え方が異なる場合があり、完全一致は保証しない。

## 数える単位

- **書記素（見た目の1文字）**。`Intl.Segmenter('ja', { granularity: 'grapheme' })` の分割を1字とする。
- 正規化（NFC / NFD）はしない。「か＋゛」（2コードポイント）も「が」（1コードポイント）も1字。
- 1回の走査で全項目を出す（X 換算だけは NFC 正規化が要るため別走査で、「詳しい集計」を開いているときだけ計算）。

## 項目の定義

| 項目 | 定義 |
|---|---|
| 文字数 | 書記素の数。改行（CRLF / LF / CR）は各1字。CRLF は書記素として1つなので1字 |
| 改行を除く | 文字数から改行を除いた数 |
| 空白・改行を除く | さらに `\p{White_Space}` のみで構成される書記素（半角・全角スペース、タブ、NBSP など）を除く。**ゼロ幅スペース U+200B は White_Space ではないため、文字として数える** |
| 行数 | 改行数＋1。空文字は0。末尾が改行のときの最後の空行も1行に数える（一般的なエディタと同じ） |
| 改行数 | CRLF / LF / CR をそれぞれ1。U+2028・U+2029・U+0085 は改行として扱わず、空白（White_Space）として数える |
| 段落数 | 空白以外を含む行の数。日本語原稿の「改行＝段落」の慣行に合わせた。空行で区切る方式（連続した空行で1段落）とは数が異なる |
| コードポイント | UTF-16 のサロゲートペアを1と数えた個数（孤立サロゲートは各1） |
| UTF-16 単位 | `String#length`。HTML の `maxlength` や JavaScript の `length` はこの単位 |
| UTF-8 バイト | `TextEncoder` でのバイト数。ブラウザの入力欄は改行を LF に正規化するので、CRLF の原稿でも LF（1バイト）換算になる。孤立サロゲートは U+FFFD（3バイト）になる |
| 字種 | 下記。空白・改行を除いた書記素を、絵文字以外は先頭コードポイントで1つに分類（結合文字付きは先頭の字で判定） |
| 全角・半角（簡易） | 空白・改行を除いた書記素の先頭が U+0000–007E または U+FF61–FF9F（半角カナ）なら半角、それ以外は全角。East Asian Width の完全実装ではない（例: `é` U+00E9 は全角に入る）。ライブラリを足さないための簡易判定で、表の内蔵は拡張候補 |
| X 換算 | 下記 |
| 原稿用紙（20×20） | 下記 |

## 字種の判定（2026-11-06 に Node v26.12.1 で実測）

実測結果（`\p{Script=…}` による判定）:

| 文字 | U+ | 実測 |
|---|---|---|
| 々 | 3005 | Script=Han |
| 〇 | 3007 | Script=Han |
| 〆 | 3006 | **Script=Common**（Han ではない） |
| ヶ ヵ | 30F6 / 30F5 | Script=Katakana |
| ー | 30FC | **Script=Common**（Script_Extensions に Hiragana・Katakana） |
| ｰ（半角長音） | FF70 | **Script=Common** |
| ゝ | 309D | Script=Hiragana |
| ヽ | 30FD | Script=Katakana |
| ・ | 30FB | Script=Common |
| ｱ（半角カナ） | FF71 | Script=Katakana |
| ﾞ（半角濁点） | FF9E | Script=Common（ただし直前の半角カナと1書記素になる） |

仕様として固定した分類:

- **ひらがな** `\p{Script=Hiragana}`（ゝゞ含む）。
- **カタカナ** `\p{Script=Katakana}`（ヶヵ・半角カナ含む）＋ **長音符「ー」U+30FC と半角「ｰ」U+FF70 を明示的に含める**（Common のため、含めないと記号になってしまう）。「・」は記号に分類する。
- **漢字** `\p{Script=Han}`（「々」「〇」を含む）＋ **「〆」U+3006 を明示的に含める**。
- **英字** `\p{Script=Latin}`（半角・全角、アクセント付きラテン文字を含む）。ギリシャ文字・キリル文字は「記号・その他」。
- **数字** `0-9` と `０-９`。ローマ数字・丸数字などは「記号・その他」。
- **絵文字** 書記素全体が `\p{RGI_Emoji}`（v フラグ。ZWJ 結合・国旗・肌色修飾・キーキャップ・異体字セレクタ付きを1つとして判定）。`©` `®` や、異体字セレクタなしの `❤` は絵文字に数えない。v フラグ非対応の環境では `\p{Extended_Pictographic}` などで代替（精度が少し下がる）。
- **記号・その他** 上のいずれにも当たらないもの（句読点・括弧・ギリシャ文字など）。

「長音符は直前の字種に従う」といった文脈判定はしない（先頭コードポイントだけで決める）。

## X（旧 Twitter）換算

- **出典**: twitter-text（Apache-2.0）`config/v3.json` — https://github.com/twitter/twitter-text/blob/master/config/v3.json （raw を取得して確認: 2026-11-06）
- 取得した値: `maxWeightedTweetLength: 280`、`scale: 100`、`defaultWeight: 200`、`transformedURLLength: 23`、`emojiParsingEnabled: true`、`ranges`＝[0–4351]・[8192–8205]・[8208–8223]・[8242–8247]（いずれも `weight: 100`。つまり U+0000–10FF、U+2000–200D、U+2010–201F、U+2032–2037 を1、それ以外を2）。
- 実装: NFC 正規化 → URL（`https?://` から空白までの連続。末尾の `.,;:!?)]}'"。、」』）` は含めない）を一律23 → 残りを書記素ごとに、絵文字（RGI_Emoji）は2、それ以外は各コードポイントの重みを合計 → 重み÷`scale` を切り上げ。上限 280 に対する「あと n」「n オーバー」を表示。
- URL 判定は簡易版で、公式のパーサー（`parseTweet`）とは一致しない場合がある。そのためこの値は目安。X の仕様は変わりうるので、実運用では投稿画面の表示を優先する。

## 原稿用紙（20×20）

- 改行ごとに新しい行にし、1行20マスで折り返したときの行数を数える（空行も1行）。枚数＝行数÷20の切り上げ。末尾が改行のときの最後の空行は行に数えない。
- 空白（スペース・タブ）は1マスを使う。禁則処理・ぶら下げ・半角2字1マス・段落の字下げは**考慮しない**（拡張候補）。
- 「改行を除く文字数 ÷ 400」の単純換算も併記する（小数1桁）。
- 原稿用紙換算の流儀は、÷400、20字折返し、禁則つきの3通りがあり、サイトにより結果が違う（docs/research.md）。

## 上限

- 基準は「文字数」「改行を除く」「空白・改行を除く」から選ぶ（既定は文字数）。残りは「あと n 字」、超過は「n 字オーバー」。
- 上限は0以上の整数（全角数字も受け付ける）。不正な入力はエラーとして表示する。

## 他ツールと数え方が違う代表例

| 比較対象 | 違い | 確度 |
|---|---|---|
| JavaScript の `length`・HTML の `maxlength` | UTF-16 単位のため、絵文字（😀）が2、ZWJ 結合絵文字が複数になる。本ツールの「UTF-16 単位」と同じ値 | 高（言語仕様） |
| Word の「文字数（スペースを含めない）」 | 数え方の細部（全角スペース・改行・特殊文字の扱い）は版により異なる。本ツールの「空白・改行を除く」と一致するとは限らない | 低（Word 側の定義は未確認） |
| X（旧 Twitter） | 日本語など範囲外の文字を2、URL を23と換算する（上の節） | 高（config/v3.json） |

確認できていないものは載せない方針のため、Word は「異なる場合がある」とだけ記す。
